Overview

The Salat-e-Mustaqeem API provides accurate Islamic prayer times, Hijri calendar conversion, and Qibla direction calculations. It's designed to be easy to integrate into any application that requires Islamic prayer time data.

Our API is built on modern web standards and is fully RESTful. All responses are returned as JSON, making it easy to parse and use in any programming language.

The base URL for all API requests is:

All endpoints return a consistent response format with a <c>success</c> boolean and a <c>data</c> object containing the requested information. In case of errors, an <c>error</c> object is returned with details about what went wrong.
