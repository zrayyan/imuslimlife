New: MCP server

Prayer times for your AI assistant

Connect Claude, ChatGPT, Gemini or Copilot to the Muslim Companion prayer-times server. Your assistant then answers with real calculated times for your city and method, not a guess.

https://alexa.imuslimlife.com/v1/mcp

What your assistant can do

Six read-only tools. Times are calculated for the place’s own timezone, with your choice of calculation method and Asr madhab.

Prayer times for any day

Fajr, Sunrise, Dhuhr, Asr, Maghrib and Isha for a place and date, in local time, with the Hijri date. get_prayer_times

Next prayer

Which prayer is next, its time and how many minutes until it. get_next_prayer

Find a place

Turns a city or address into coordinates and a timezone. find_location

Hijri date

The Islamic date for any Gregorian date. get_hijri_date

Qibla direction

Direction of the Kaaba from any place, in degrees and as a compass point. get_qibla_direction

Calculation methods

ISNA, Muslim World League, Umm al-Qura, Karachi and 11 more, plus Hanafi or standard Asr. list_calculation_methods

Set it up

Claude

  1. On claude.ai or in Claude Desktop, open Settings → Connectors.
  2. Choose Add custom connector. Name it Muslim Companion and paste the server URL below.
  3. Save. In a chat, turn the connector on (from the tools menu) and ask: “When is Maghrib in Toronto today?”

Custom connectors depend on your Claude plan. For Claude Code, run the command below instead.

https://alexa.imuslimlife.com/v1/mcp
claude mcp add --transport http muslim-companion https://alexa.imuslimlife.com/v1/mcp

ChatGPT

  1. In ChatGPT, open Settings → Apps & Connectors, then Advanced settings, and turn on Developer mode.
  2. Choose Create (new connector). Name it Muslim Companion, paste the server URL below, and choose No authentication.
  3. In a new chat, add the connector and ask: “What are today’s prayer times in London, Hanafi Asr?”

Developer mode connectors depend on your ChatGPT plan, and menu names can change between versions.

https://alexa.imuslimlife.com/v1/mcp

Gemini CLI

  1. Open ~/.gemini/settings.json (create it if it doesn’t exist).
  2. Add the muslim-companion entry below under mcpServers, then restart Gemini CLI.
  3. Run /mcp to check it’s connected, then ask about prayer times.
{
  "mcpServers": {
    "muslim-companion": {
      "httpUrl": "https://alexa.imuslimlife.com/v1/mcp"
    }
  }
}

Copilot / VS Code

  1. In your project, create .vscode/mcp.json (or run MCP: Add Server from the Command Palette and choose HTTP).
  2. Paste the configuration below and click Start above the server entry.
  3. In Copilot Chat, switch to Agent mode and ask about prayer times.
{
  "servers": {
    "muslim-companion": {
      "type": "http",
      "url": "https://alexa.imuslimlife.com/v1/mcp"
    }
  }
}

Developers

  1. Any MCP client can connect: the server speaks Streamable HTTP, is stateless, and needs no API key.
  2. Call a tool with a JSON-RPC POST, as in the example below.
  3. Read llms.txt for a short overview written for language models.

Limits: 60 requests per minute and 600 per hour per client. Please cache a day’s times instead of asking repeatedly.

curl -s https://alexa.imuslimlife.com/v1/mcp -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_prayer_times","arguments":{"latitude":43.6532,"longitude":-79.3832,"method":2}}}'

Try asking: “When is Fajr tomorrow in Orlando?” · “Which way is the qibla from Karachi?” · “What is today’s Hijri date?” · “How long until Asr in Toronto, Hanafi?”

Public data only

The server only provides public information: prayer times, Hijri dates, qibla directions and calculation methods. It needs no account and cannot see or change anything in your Muslim Companion settings. Features that act for you, such as reading your own Athan schedule, will come later and will always require you to sign in and approve access. See our Privacy Policy.
